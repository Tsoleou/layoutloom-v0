# 03 — 行首標點守則(共用 composer,標題+副標)

**What to build:** 標題或副標換行時,任何一行都**不得以標點符號開頭**(CJK 或 ASCII 皆然)。行首若出現標點,**預設把該標點移回上一行行尾**(追い込み);若移回會使上一行超出寬度預算(爆框),則**直接刪除**該標點。以「含逗號、在邊界換行的副標」驗收:換行後第二行不以逗號/句號起首。

**節點對照:**
- **機制落在共用 composer**(既有的 kinsoku / 組行邏輯),由 **Adapt Layout 節點(v1)** 與 **Layout Guard 節點(v0)** 共同呼叫——一套規則兩邊生效。
- 純幾何 / 版面守則,**Master Design 模型不參與**;延續 ADR-0006「一套 composer 共用」。
- 目前 kinsoku 僅認 CJK 收尾標點且一律移回;本 ticket 擴充為:行首標點集合納入 **ASCII**,並加入「爆框則刪除」的後備。

**Blocked by:** 01(ADR-0008 定案後開始)。與 02 互不阻擋,可並行。

**Status:** done
